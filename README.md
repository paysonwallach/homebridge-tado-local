# homebridge-tado-local

Exposes each [AmpScm/TadoLocal](https://github.com/AmpScm/TadoLocal) zone as
a HomeKit `Thermostat` via Homebridge. Local only — Homebridge talks to
TadoLocal's REST/SSE API, never Tado's cloud.

## Config (`config.schema.json` / Homebridge UI)

| Field | Required | Default | Notes |
|---|---|---|---|
| `host` | yes | — | TadoLocal's Docker host, not the bridge |
| `port` | yes | `4407` | confirm against `/docs` |
| `bearerToken` | yes | — | generated by TadoLocal — check its startup logs / Setup UI |
| `pollIntervalSeconds` | no | `60` | fallback only; SSE drives most updates |

## Build

```sh
npm install
npm run build
```

## Install into Homebridge

Link or publish, then add a `TadoLocal` platform block to Homebridge's
`config.json` (or via the UI, using `config.schema.json` above).
